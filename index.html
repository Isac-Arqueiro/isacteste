📡 Streaming online

Cole o endereço direto do áudio da sua rádio (por exemplo, um link de streaming Icecast/Shoutcast). O link precisa permitir reprodução no navegador.

Se o link usar HTTP e seu site estiver em HTTPS, o navegador pode bloquear o áudio. Prefira URL HTTPS.

Como conseguir uma transmissão própria?

Para transmitir ao vivo para outras pessoas, você precisa de um servidor de streaming (por exemplo, Icecast) e um programa emissor no computador. O player desta página pode receber a URL pública do fluxo. Esta página sozinha não envia o microfone para a internet.

⚙ Painel administrativo

Personalize a rádio e gerencie suas músicas. A senha abaixo é uma trava simples da interface, não uma segurança de servidor.

Instalação e limitações

Para instalação como PWA, publique os arquivos em um site HTTPS. Para uso local, abra index.html em um navegador moderno; algumas funções de instalação e armazenamento podem variar. O armazenamento do navegador pode ser apagado pelas configurações do aparelho. Faça exportações de backup.
